# Ultra Renova — prototype

A first website proposal for reviewing the layout and content with the client.

The page uses the supplied current logo, company information and photographs of one completed pergola/barbecue project. AI-generated house images from the brochure are not presented as completed projects.

This static prototype includes responsive navigation, expandable service descriptions, a project gallery and an email message preparation form. The form does not automatically send messages.

Open the GitHub Pages publication to review the site. The HTML, stylesheet, JavaScript and assets are all in this repository; no build step is needed.
